==================
final and non-sealed implementations
==================

sealed interface Vehicle permits Car, Bike {
  int wheels()
}

final class Car implements Vehicle {
  public int wheels() {
    return 4
  }
}

non-sealed class Bike implements Vehicle {
  public int wheels() {
    return 2
  }
}
